# Skill: Web Prototype

## Overview

The **web-prototype** skill enables rapid creation of interactive web prototypes using modern HTML, CSS, and JavaScript frameworks. It supports responsive layouts, component-based architecture, and integration with popular CSS frameworks like Tailwind CSS.

## Output Format

- **Primary**: Standalone HTML file with embedded CSS and JavaScript
- **Frameworks**: Tailwind CSS, Bootstrap, or custom CSS
- **Interactive**: Full support for user interactions and animations

## Capabilities

### Design Generation
- Responsive web layouts (mobile-first approach)
- Navigation systems (header, sidebar, tabs)
- Content sections (hero, features, pricing, testimonials)
- Form elements (input, buttons, select, checkbox, radio)
- Cards, modals, and overlay components
- Data visualization components (charts, tables)

### Styling Options
- Tailwind CSS utilities
- Custom CSS with CSS variables
- Dark mode support
- CSS animations and transitions
- CSS Grid and Flexbox layouts

### Interactivity
- Form validation
- Accordion and tab switching
- Carousel and slider components
- Modal dialogs
- Dropdown menus
- Smooth scroll navigation

## Example Prompt

```
Create a landing page for a SaaS product with:
- Hero section with headline and CTA button
- Features grid with 6 items
- Pricing section with 3 tiers
- Testimonials carousel
- Footer with links and social icons
- Mobile responsive design
- Dark mode support
```

## Output Structure

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Web Prototype</title>
  <!-- Tailwind CSS CDN or inline styles -->
</head>
<body>
  <!-- Semantic HTML structure -->
  <!-- Interactive components with JavaScript -->
</body>
</html>
```

## Technical Notes

- All prototypes are self-contained single HTML files
- Use Tailwind CSS CDN for rapid styling
- Include placeholder images via Unsplash or similar
- Ensure WCAG 2.1 accessibility compliance
- Optimize for cross-browser compatibility
